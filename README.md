# FoodExpiryApp — прототип 2.0

FoodExpiryApp

Статус: Beta (0.2.0)

Умное приложение для контроля сроков годности продуктов. Сканируйте коды Честного ЗНАКа, фотографируйте даты производства и следите за всем, что происходит с вашими продуктами.
Что уже работает

· Сканирование DataMatrix (Честный ЗНАК): Приложение распознает коды маркировки, извлекает GTIN и серийный номер товара.
· Распознавание сроков годности (OCR): Сфотографируйте дату на упаковке, и встроенный OCR-движок (на базе ML Kit) автоматически распознает её и подставит в карточку.
· Локальная база данных: Все продукты сохраняются в SQLite на устройстве.
· Кастомизация: Поддержка светлой, темной и черной тем, а также выбор акцентного цвета и иконки приложения (через activity-alias).
· Локализация: Полноценная поддержка русского и английского языков интерфейса.
· Список покупок: Рабочий список с возможностью добавлять товары вручную, ставить галочки (куплено/не куплено) и использовать шаблоны.
· Базовая статистика: Подсчет общего количества продуктов, просроченных позиций и ближайших сроков. Графики рисуются на чистом C# (без сторонних библиотек).


В разработке (Work in Progress)

Проект находится в активной стадии разработки. Следующие функции запланированы, но пока не реализованы полностью:

·  Синхронизация и Аккаунты: В планах — интеграция с облачным бэкендом (Supabase/Firebase) для синхронизации между устройствами.
·  Интерактивная карта и магазины: Пока на месте карты отображается заглушка. Интеграция с картами (OSM или 2GIS) и вывод реальных магазинов поблизости находится в стадии проектирования.
·  Интеграция с магазинами (API): Оценка стоимости продуктов в статистике работает на основе локального «каталога цен». В будущем планируется подключение API магазинов (например, 2GIS или Сбер маркет, ближайших торговых точек рядом с вами) для получения реальных цен и акций.
·  Расширенная статистика: Планируется добавление более глубоких аналитических отчетов и графиков.

 Технологическая база:

· Платформа: .NET MAUI (C#)
· Сканирование: ZXing.Net.Maui
· Распознавание текста: Plugin.Maui.OCR (Google ML Kit)
· База данных: SQLite-net-pcl
· UI/Анимации: CommunityToolkit.Maui

⚠️ Известные ограничения и проблемы (Known Issues)

Примечание о сборке и API (Visa/MasterCard): 
В связи с отсутствием возможности использовать карты Visa/MasterCard в текущем регионе (Казахстан), соответственго к платным API (например, Google Maps API Key). Именно поэтому я использую пока только заглушки. В будущем будет нормальные API и соответственно полноценные функции.
