# FoodExpiryApp — прототип по последнему ТЗ

.NET MAUI Android, интерфейс для планшета. Исходный проект; APK не приложен и сборка на Android-устройстве не подтверждена.

Включено: главное меню, поиск, три плотности списка, полупрозрачные подложки категорий, отдельные цветные овалы сроков, группировка одинаковых товаров с количеством только при количестве > 1, локальная SQLite база, формы добавления, настройки, экран Инфо, экран поддержки (70/120/500 ₽, без реального платёжного подключения).

Ограничения: сканер и Честный ЗНАК не подключены; синхронизация времени пока демонстрационная; выбор фото и точные изображения из каталога не реализованы в этой версии. Цвет срока — визуальная подсказка, не гарантия безопасности продукта.

Сборка: требуется .NET SDK с workload maui-android и Android SDK. Откройте FoodExpiryApp.sln в Visual Studio 2022 или выполните dotnet build FoodExpiryApp/FoodExpiryApp.csproj -f net8.0-android.
