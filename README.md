# FoodExpiryApp — прототип 2.0

.NET MAUI Android, интерфейс для планшета. Исходный проект; APK не приложен и сборка на Android-устройстве не подтверждена.

Включено: главное меню, поиск, три плотности списка, полупрозрачные подложки категорий, отдельные цветные овалы сроков, группировка одинаковых товаров с количеством только при количестве > 1, локальная SQLite база, формы добавления, настройки, экран Инфо, экран поддержки (без реального платёжного подключения).

Ограничения: сканер и Честный ЗНАК не подключены; выбор фото и точные изображения из каталога не реализованы в этой версии. Цвет срока — визуальная подсказка.

Сборка: требуется .NET SDK с workload maui-android и Android SDK. Откройте FoodExpiryApp.sln в Visual Studio 2022 или выполните dotnet build FoodExpiryApp/FoodExpiryApp.csproj -f net8.0-android.
